# Personal Portfolio Website

A clean, static personal portfolio built as a hands-on exercise to practice core **HTML5** and **CSS3** fundamentals, structure, and styling techniques.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic elements, page structure, and content markup.
- **CSS3**: Custom styling, layout positioning, colors, and typography.

---

## ✨ Features

- **Header / Navigation**: Quick navigation section to jump between sections.
- **About Me**: Brief personal introduction and background.
- **Projects Section**: Highlights of personal coding projects and practice exercises.
- **Skills**: Visual display of core technical skills and tools.
- **Contact Info**: Links and details to get in touch.
